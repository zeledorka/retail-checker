# ai-courtroom (frontend)

See the repo root `CLAUDE.md`. Quick start:

```bash
npm install
cp .env.example .env.local
npm run dev
```

`/play` = player (mobile). `/projector` = courtroom display + host dock (`U` unlock, `H` hide, `?view=display` = no dock).
Runs in mock mode by default (`NEXT_PUBLIC_USE_MOCK=1`).
